# Landmill - Tailwind CSS Landing Page

A modern, fast, and fully responsive landing page template built with Tailwind CSS. Perfect for SaaS, startup, agency, and product websites.

Cloned and customized from the original Landmill / Landwind template for learning and portfolio purposes.
